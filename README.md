# Vel Alankara - Jewelry Catalog Website

A responsive digital catalog designed for showcasing South Indian traditional temple jewelry, featuring categorized browsing and direct WhatsApp order inquiries.

🔗 **Live Demo:** [vel-alankara.netlify.app](https://vel-alankara.netlify.app/)

---

### ✨ Features
- **Categorized Browsing:** Filter by necklaces, harams, jhumukas, bangles, and bridal collections.
- **WhatsApp Direct Order:** One-click customer inquiry pre-filling selected item details.
- **Responsive Layout:** Clean desktop and mobile viewing with custom typography.

---

### 🛠️ Built With
- **HTML5 & CSS3** (Custom typography with Google Fonts `DM Serif Display` & `Montserrat`)
- **JavaScript** (Filter logic and UI interactivity)
- **Netlify** (Continuous cloud hosting)
